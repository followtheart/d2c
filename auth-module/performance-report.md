## 性能优化建议

### 高优先级优化

#### 1. 异步邮件发送
**当前问题：** 邮件发送阻塞主流程  
**优化方案：** 使用消息队列异步发送  
**预期收益：** 注册响应时间减少 100ms（30%提升）

```typescript
// 优化前（同步）
await this.emailService.sendVerificationCode(email, code);

// 优化后（异步）
this.emailQueue.add('sendVerification', { email, code });
```

#### 2. 用户数据缓存
**当前问题：** 每次请求都查询数据库  
**优化方案：** Redis缓存热点用户数据  
**预期收益：** 登录响应时间减少 50ms（25%提升）

```typescript
// 缓存策略
const cacheKey = `user:${email}`;
const cachedUser = await redis.get(cacheKey);
if (cachedUser) return cachedUser;

const user = await db.findByEmail(email);
await redis.setex(cacheKey, 300, user); // TTL: 5分钟
```

### 中优先级优化

#### 3. bcrypt cost动态调整
**建议：** 根据服务器性能动态调整cost factor  
- 高性能服务器：cost = 14
- 普通服务器：cost = 12（当前）
- 低性能服务器：cost = 10

#### 4. 数据库索引优化
**建议：** 为常用查询字段添加索引
- email字段：唯一索引 ✓
- resetToken字段：索引（用于密码重置）
- verificationCode字段：索引（用于邮箱验证）

### 低优先级优化

#### 5. JWT令牌缓存
**建议：** 缓存已验证的令牌（短期）
```typescript
const cacheKey = `token:${token}`;
const cachedPayload = await redis.get(cacheKey);
```

#### 6. 连接池优化
**建议：** 配置合理的数据库连接池
- 最小连接数：5
- 最大连接数：20
- 空闲超时：30秒
